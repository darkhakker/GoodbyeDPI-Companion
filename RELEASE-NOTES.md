# GoodbyeDPI Companion 0.1.3 — список сайтов и простой интерфейс

- Исправлено падение popup на отсутствующих данных installer при обновлении фонового worker.
- Список отрисовывается независимо от состояния установки, ошибки связи не стирают карточки.
- Проверено сохранение после закрытия popup и перезапуска фонового worker; повторное добавление без дубликатов.
- Из главного окна убраны технический ID, длинные пояснения и список служебных ресурсов.
- В основном окне остаются переключатель, добавление и список сайтов. Режимы и ресурсы раскрываются отдельно.

Обновление: замените файлы расширения и нажмите кнопку обновления в chrome://extensions / edge://extensions.
Не удаляйте расширение: его список хранится в storage.local и сохраняется при обновлении с тем же ID.
Компонент Windows переустанавливать не нужно; версия native-компонента остаётся 0.1.2.

19 тестов JavaScript, сборка Windows и тесты протокола включены в CI.
