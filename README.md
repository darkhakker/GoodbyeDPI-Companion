# GoodbyeDPI Companion — предварительная версия 0.1.3

[Скачать расширение](https://github.com/darkhakker/GoodbyeDPI-Companion/releases/download/v0.1.3-preview.1/GoodbyeDPI-Companion-Extension.zip) · [Установщик Windows](https://github.com/darkhakker/GoodbyeDPI-Companion/releases/download/v0.1.3-preview.1/GoodbyeDPI-Companion-Setup.exe)

Это предварительная сборка; установка на чистой Windows и работа у конкретного провайдера ещё требуют проверки.

Расширение Chrome/Edge для управления локальным GoodbyeDPI в Windows 10/11.
В комплекте: исходники, расширение Manifest V3, компонент Native Messaging,
служба Windows, установщик и официальные зависимости GoodbyeDPI 0.2.3rc3-2.

## Быстрый запуск

1. Откройте `chrome://extensions` или `edge://extensions`, включите режим разработчика.
2. Нажмите «Загрузить распакованное расширение» и выберите папку `extension`.
   Для скачанного `GoodbyeDPI-Companion-Extension.zip` сначала распакуйте архив.
3. Если компонент Windows отсутствует, расширение автоматически скачает
   `GoodbyeDPI-Companion-Setup.exe` и откроет страницу первого запуска.
   Откройте скачанный установщик и подтвердите запрос администратора Windows.
   Файлы распакуются автоматически; ссылки, драйверы и зависимости указывать не нужно.
4. Откройте расширение, нажмите ↻. Добавьте `tiktok.com` или другой сайт.
5. Остановите старую службу GoodbyeDPI и обычный START-restored.cmd, если они работают.
   Новая программа не останавливает их самостоятельно, а сообщает о конфликте.
Режим обхода находится в раскрывающихся «Настройках». Ресурсы сайта спрятаны в его карточке.

6. Нажмите «Включить». Посетите сайт, подождите несколько секунд и обновите страницу:
   новые сторонние ресурсы добавляются автоматически и применяются с задержкой.

Служба называется `GoodbyeDPICompanion`. Она работает без открытого терминала.
Установка регистрирует службу, но не включает движок обхода до команды из расширения.
После последующего включения выбранное состояние сохраняется между перезагрузками.

## Какие домены обрабатываются

- Добавление `www.site.co.uk` превращается в `site.co.uk` по локальной Public Suffix List.
  Это включает все его поддомены, даже ещё не посещённые. DNS-перебор не нужен.
- Запросы ресурсов внутри вкладки выбранного сайта пополняют его список автоматически.
  Сохраняются точные имена сторонних ресурсов; общий CDN не расширяется до родительского домена.
- Для TikTok есть небольшой начальный набор известных семейств ресурсов.
- В карточке сайта можно исключить автоматически найденный ресурс, вернуть его или
  отключить дальнейшее обнаружение. Удаление сайта удаляет и его зависимости, кроме
  тех, которые нужны другому добавленному сайту.
- Сайты, которых нет в итоговом списке, не включаются в доменные приёмы обхода.
  Пустой список останавливает движок, а не включает обход для всех.
- Нет глобального перенаправления DNS, блокировки QUIC или режима `--allow-no-sni`.
  Каждый профиль всегда получает `--blacklist`.

Важно: WinDivert всё равно технически перехватывает подходящие TCP-пакеты на 80/443
для анализа и повторной отправки. Список ограничивает изменения по HTTP Host/TLS SNI,
а не сам факт перехвата. Это не VPN и не удалённый прокси. Обработка выбранного домена
действует во всей системе, а не только в браузере. Общий CDN, попавший в список ресурсов,
может использоваться и другими сайтами. Нельзя исключить один поддомен из явно
добавленного корневого домена: движок GoodbyeDPI поддерживает включающий список.

## Ограничения автоматического обнаружения

Невозможно заранее узнать все внешние домены сайта. Расширение видит только запросы,
которые браузер действительно сделал и разрешил наблюдать. Если основная страница
вообще не загрузилась, её ещё не выполненный JavaScript не раскрывает новые ресурсы.
В таком случае помогает начальный список сервиса или другой профиль обхода.
Новая зависимость может потребовать повторной загрузки: расширение не блокирует
сетевой запрос до перезапуска движка. Перезапуск объединяет изменения за несколько секунд;
резервная alarm-синхронизация срабатывает через 30 секунд.

Режимы ориентированы на HTTP и TLS поверх TCP. QUIC/HTTP3 и скрытый SNI/ECH могут
ограничивать результат; глобально отключать их установщик не будет. Наличие запущенного
процесса не доказывает, что сайт разблокирован. Совместимость с конкретным провайдером
нужно проверять отдельно. Автоматическое выявление всех методов DPI не реализовано.

## GitHub: что загружать

Весь этот каталог можно поместить в собственный Git-репозиторий. Личные списки доменов,
история браузера и настройки с вашего компьютера в проект не включены.

1. Создайте GitHub Release, `v0.1.3-preview.1` с отметкой Pre-release.
2. Прикрепите файлы из `release`:
   - `GoodbyeDPI-Companion-Extension.zip`;
   - `GoodbyeDPI-Companion-Setup.exe`;
   - `GoodbyeDPI-Companion-Windows.zip`;
   - `SHA256SUMS.json`.
3. Опубликуйте релиз. Адрес проекта и версия закреплены в `extension/config.js`.
   Автозагрузка использует только наш фиксированный URL Setup.exe; поля репозитория
   и возможности подменить URL через настройки расширения больше нет.
4. Не меняйте поле `key` в manifest.json — оно сохраняет ID распакованного расширения.

GitHub ZIP расширения устанавливается через режим разработчика; это не автоматическая
установка из магазина. Для обычной установки потребуется отдельно опубликовать расширение
в Chrome Web Store / Edge Add-ons, сверить выданный ID и обновить разрешённый origin
компонента Windows. Автоскачивание не даёт расширению права запустить EXE:
пользователь открывает Setup.exe и подтверждает UAC один раз. Если браузер настроен
спрашивать место сохранения или проверяет EXE, его собственные запросы сохраняются.
Архив Windows оставлен как запасной вариант ручной установки через Install.cmd.

При повторном открытии popup загрузка не повторяется. Ошибка сети, отмена или удаление
файла показываются с кнопкой повторного скачивания. Остановленная служба при наличии
host не считается отсутствующей установкой и не вызывает неожиданной загрузки.

## Сборка из исходников

Нужны Windows, Windows PowerShell 5.1 и .NET Framework 4.8 (есть в поддерживаемых
системах Windows 10/11). Для JavaScript-тестов нужен Node.js 18+; конечным пользователям
Node.js/Python/.NET SDK ставить не требуется. На Windows ARM эта версия не тестировалась.

```powershell
node --test tests/domains.test.mjs tests/background.test.mjs tests/installation.test.mjs tests/popup.test.mjs
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/Build.ps1
release/GoodbyeDPI-Companion-Windows/Companion.exe --self-test
```

`scripts/init-manifest.mjs` уже запускался. В репозитории сохранён публичный ключ
для стабильного ID распакованного расширения; закрытый ключ не хранится и не требуется.
Повторный запуск скрипта сохраняет имеющийся ключ. Если намеренно меняете ключ,
пересоберите Windows-компонент и переустановите его.

Официальный архив зависимостей закреплён SHA-256 в Build.ps1. Сборка сверяет архив,
затем формирует checksums.json для установки и SHA256SUMS.json для ZIP/EXE.
Setup.exe содержит весь Windows ZIP внутри, проверяет его SHA-256 и самостоятельно
распаковывает в отдельную папку LocalAppData перед запуском установочного сценария.
Проверка `Setup.exe --verify-payload` не устанавливает службу и драйвер.
Это контроль целостности, а не цифровая подпись и не независимая проверка издателя.
Перед публичным стабильным релизом нужны испытания на чистой Windows и подпись
собственного Companion.exe/установочного пакета. Поставляемый компонент Companion.exe
не подписан; предупреждения Windows возможны.

## Архитектура и права

`MV3 extension → Native Messaging host → локальный named pipe → служба → GoodbyeDPI`.
Один `Companion.exe` выполняет роли host и службы в разных процессах.
Веб-расширение и Native Messaging host работают без повышения прав.
Служба LocalSystem управляет только собственным дочерним движком и получает лишь
валидированный список доменов, булево состояние и один из трёх фиксированных профилей.
Произвольные команды, параметры движка, пути и загрузки по сети не принимаются.

Программа устанавливается в `%ProgramFiles%\GoodbyeDPICompanion`, состояние и журнал —
в `%ProgramData%\GoodbyeDPICompanion`. Права записи принадлежат SYSTEM/Administrators.
Named pipe разрешает управление учётной записи, установившей программу; identity
проверяется через impersonation. Этот пользователь доверенный: другое приложение
в его сессии также может отправлять допустимые команды. Другие локальные пользователи
не получают управление. Это однопользовательская предварительная версия.

Расширение запрашивает доступ HTTP/HTTPS ко всем сайтам, чтобы видеть сторонние ресурсы,
но сохраняет только имена доменов ресурсов добавленных сайтов, без URL-путей и содержимого.
Списки не отправляются на сервер. Браузер обращается на GitHub для автоматического
скачивания Setup.exe при отсутствии host, либо для явного повторного скачивания.
Разрешение downloads используется для загрузки и показа файла, не для запуска EXE.
Установка WinDivert происходит при первом запуске движка, не просто при скачивании архива.

## Удаление и диагностика

- Выключите обход в расширении.
- Запустите `Uninstall.cmd` в установленной папке или в распакованном Windows-пакете.
  Служба и регистрация Native Messaging будут удалены. Файлы, настройки и журнал
  намеренно сохраняются; при желании удалите две папки GoodbyeDPICompanion вручную.
- Удалите расширение в браузере. Это отдельно удалит его локальный список сайтов.
- Общая служба/драйвер WinDivert автоматически не удаляется: её могут использовать
  другие программы; после перезагрузки неиспользуемый драйвер выгружается.
- При ошибке установки запустите `Install.ps1` из PowerShell администратора, чтобы
  увидеть сообщение. При ошибке движка смотрите `%ProgramData%\GoodbyeDPICompanion\engine.log`.
