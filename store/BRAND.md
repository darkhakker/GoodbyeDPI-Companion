# Визуальное оформление 0.1.5

Знак: две разомкнутые дуги и центральная точка внутри круга — локальный канал и связь.
Щит, стрелка, галочка и сине-бирюзовая палитра больше не используются.

Палитра: сливовый `#4E3979`, кремовый `#FFF6E9`, янтарный `#EFAE68`,
светлая поверхность `#FBF8F3`, тёмная поверхность `#211B2B`.

В popup используется компактная системная типографика. Материалы магазина имеют
светлый двухцветный фон, интерфейс слева, пояснение справа и заголовки с засечками.
Исходный SVG находится в extension/icons/icon.svg. PNG воспроизводятся Build-Icons.ps1.

Изображения магазина: store/images. Их размеры и отсутствие alpha у скриншотов
проверяются отдельно. У иконки 128×128 есть прозрачные поля.

Повторный рендер (нужен только разработчику, не пользователю):

```powershell
npm install --prefix store --ignore-scripts --no-audit --no-fund
node store/render-assets.mjs
```

Рендер запускает отдельный headless Chrome с новым временным профилем и локальным
HTTP-сервером. Личные окна, аккаунты и пользовательские вкладки не используются.
Данные демонстрационные; сам интерфейс отрисовывается настоящим кодом popup.
