GoodbyeDPI Companion

Перед первым запуском

Расширение обрабатывает домены открываемых вкладок и домены запросов выбранных сайтов, чтобы находить их ресурсы.

Список хранится на этом устройстве и передаётся только локальной службе GoodbyeDPI. Разработчику эти данные не отправляются.

Для работы нужен компонент Windows. После продолжения его установщик будет скачан с GitHub, если требуется установка или обновление. Запуск и права Windows подтверждаете вы.

Один шаг в Windows

Установщик загружается автоматически. Откройте GoodbyeDPI-Companion-Setup.exe из загрузок браузера и подтвердите запрос администратора Windows.

Программа сама распакует и установит компоненты. После установки вернитесь в расширение, добавьте сайт и включите обход.

Ссылки, драйверы и зависимости уже включены. Браузер не может самостоятельно запустить EXE и подтвердить UAC.
