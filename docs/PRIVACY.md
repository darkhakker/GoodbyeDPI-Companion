# Политика конфиденциальности GoodbyeDPI Companion

Дата вступления в силу: 31 октября 2026 года. Версия продукта: 0.1.5.

Издатель проекта: **darkhakker**. Исходный код, поддержка и обращения:
https://github.com/darkhakker/GoodbyeDPI-Companion/issues

GoodbyeDPI Companion — расширение Chrome/Edge и устанавливаемый отдельно локальный
компонент Windows для управления GoodbyeDPI на выбранных пользователем сайтах.
Это не VPN и не сервис анонимизации. Продукт не направляет трафик на сервер разработчика.

## Согласие и назначение обработки

При первом запуске расширение объясняет обработку доменов и загрузку необходимого
Windows-компонента. До нажатия «Разрешить и продолжить» оно не наблюдает запросы
для обнаружения ресурсов, не запоминает адреса вкладок и не начинает загрузку EXE.
Настройки и ранее добавленные сайты не удаляются при таком ожидании согласия.

Сведения используются только для показа текущего сайта, ведения выбранного списка,
обнаружения реально запрошенных ресурсов и управления локальным обходом DPI.

## Что обрабатывает расширение

- **Текущая вкладка:** расширение читает её URL, чтобы выделить имя домена для кнопки
  добавления. Пути, параметры URL и фрагменты не сохраняются и не отправляются службе.
- **Навигации и ошибки загрузки:** в `chrome.storage.session` сохраняется только
  последнее имя хоста и признак неудачной загрузки для каждой открытой вкладки.
  Это позволяет предложить добавление сайта даже на странице сетевой ошибки.
  Эти записи находятся в памяти, удаляются при закрытии вкладки и не являются архивом истории.
- **Ресурсы выбранных сайтов:** наблюдаются метаданные HTTP/HTTPS-запросов браузера.
  Сохраняются точное имя хоста ресурса, исходный выбранный сайт, время первого
  обнаружения, тип ресурса, домен инициатора (если браузер его сообщил) и способ привязки.
  Содержимое страниц, тела запросов/ответов и cookies не запрашиваются через API расширения.
- **Настройки:** выбранные сайты, обнаруженные ресурсы, исключения, режим обхода,
  состояние включения и отметка согласия сохраняются в `chrome.storage.local`.
  Это локальное хранилище профиля; расширение не использует `chrome.storage.sync`.
- **Загрузка компонента:** локально сохраняются ID загрузки Chrome, имя файла,
  прогресс, ошибка и версия установщика. Эти сведения нужны для показа файла и
  предотвращения повторных загрузок. Расширение не читает содержимое других загрузок.

Расширение не считывает пароли, платёжные сведения, тексты переписки, поля форм,
содержимое документов, нажатия клавиш, перемещения мыши или рекламные идентификаторы.
Само расширение не получает имя пользователя Windows или SID учётной записи.

## Локальный компонент Windows

Пользователь сам запускает скачанный установщик и подтверждает повышение прав Windows.
Установщик регистрирует Native Messaging host и службу `GoodbyeDPICompanion`.
Расширение передаёт ей через локальный Native Messaging / named pipe только
итоговый список доменов, выбранный профиль и состояние включения.

Компонент использует **SID учётной записи Windows** для ограничения доступа к службе
и записывает его локально в установленную папку. Системные пути и технические сведения
могут присутствовать в журналах установки и диагностики. Эти идентификаторы и журналы
не передаются разработчику автоматически.

GoodbyeDPI/WinDivert локально анализирует подходящие сетевые пакеты, включая HTTP Host
и TLS SNI. Он не расшифровывает HTTPS и не создаёт удалённый VPN-туннель.
Изменения по доменным правилам применяются во всей Windows. Работа службы может
продолжаться после закрытия браузера, если пользователь оставил движок включённым.
Общие CDN могут использоваться несколькими сайтами.

## Передача данных и сторонние сервисы

Разработчик не получает списки сайтов, историю запросов, содержимое страниц,
статистику использования, SID или автоматические отчёты об ошибках.
В продукте нет рекламы, аналитики, телеметрии и встроенной регистрации аккаунта.
Данные не продаются и не используются для рекламы или оценки платёжеспособности.

После согласия, если компонент отсутствует или требует обновления, браузер загружает
фиксированный файл установщика из Releases репозитория
https://github.com/darkhakker/GoodbyeDPI-Companion.
GitHub и его инфраструктура доставки видят обычные сведения сетевого соединения,
например IP-адрес, User-Agent и адрес запрашиваемого файла, в соответствии со своими
правилами. Список сайтов и домены обнаруженных ресурсов в этот запрос не включаются.
Ссылка политики/поддержки также открывает GitHub; это отдельное обращение браузера.

https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

При добровольном обращении в Issues сообщение становится публичным.
Не размещайте там приватные URL, полные журналы с персональными сведениями или секреты.

## Хранение, управление и удаление

- Записи ресурсов хранятся локально до удаления соответствующего сайта/ресурса,
  очистки хранилища расширения или удаления расширения. Обновление с тем же ID сохраняет список.
- Можно выключить обнаружение ресурсов для отдельного сайта, исключить сторонний ресурс,
  удалить сайт или выключить движок.
- Кнопка «Отключить обработку доменов» отзывает согласие, отключает наблюдение расширения,
  очищает временные сведения вкладок и запрашивает выключение локального движка.
  Сохранённый список остаётся, пока пользователь его не удалит.
- Файлы Windows-компонента находятся в `%ProgramFiles%\GoodbyeDPICompanion`,
  настройки, список движка и журнал — в `%ProgramData%\GoodbyeDPICompanion`.
  Журнал движка ограничивается приблизительно 1 МБ с очисткой при следующей записи.
- `Uninstall.cmd` удаляет службу и регистрацию браузера, но оставляет локальные файлы
  для диагностики. Для полного удаления после остановки/удаления службы удалите эти
  две папки и кэш установщиков `%LocalAppData%\GoodbyeDPICompanion\Setup`, а также расширение.
  Общий драйвер WinDivert автоматически не удаляется, поскольку может использоваться другими программами.

## Ограниченное использование

Использование информации, полученной через API Chrome/Google, соответствует Chrome Web Store
User Data Policy, включая требования Limited Use. Данные используются только для
описанных пользовательских функций. Они не используются для рекламы, продажи,
передачи брокерам данных или несвязанных с продуктом целей.

Вопросы и запросы об этой политике: https://github.com/darkhakker/GoodbyeDPI-Companion/issues

## Изменения

Актуальная версия публикуется по этому адресу вместе с датой. Существенные изменения
обработки данных потребуют обновления уведомления и согласия внутри расширения.
