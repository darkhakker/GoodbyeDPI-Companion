Подготовлено для **уже созданной** карточки:
`fodhcnbgkempfhhmolplgmgjaamcfbia`.

## Что сделать в кабинете

1. Откройте существующий продукт, раздел **«Пакет»**. Загрузите новый
   `GoodbyeDPI-Companion-WebStore-0.1.5.zip`. Не создавайте новый продукт:
   магазинный ID уже встроен в Windows-компонент. В ZIP manifest.json находится в корне,
   поле key для распакованной версии удалено, EXE/DLL/SYS внутрь не входят.
2. В **«Описании продукта»** скопируйте текст из `01-LISTING-RU.txt`.
   Название и короткое описание берутся из нового пакета. Укажите русский язык.
3. Загрузите изображения по таблице ниже. Видеоролик можно оставить пустым.
4. В **«Конфиденциальности»** используйте `02-PRIVACY-FIELDS-RU.txt`: единая цель,
   объяснения всех разрешений, раскрытие локальной обработки и ссылка политики.
   Не выбирайте «данные не обрабатываются»: локальные домены и сетевые метаданные тоже обрабатываются.
5. В **«Инструкциях для тестирования»** вставьте `03-REVIEWER-INSTRUCTIONS-EN.txt`.
   Логин и пароль не нужны. Обязательная Windows-зависимость указана явно.
6. Для первого выпуска выберите **«Доступ по ссылке / Unlisted»**, если нужен
   ограниченный старт без поиска по магазину. Это всё равно требует модерации Google.
   Публичную доступность можно выбрать вместо этого, если продукт уже готов для широкой аудитории.
7. Сохраните черновик. Проверьте сообщения кнопки **«Почему я не могу запросить проверку?»**.
   Отправляйте на проверку после проверки заполненных полей и Windows-связки.

## Переход с распакованной версии

У распакованной версии ID `abbnpgbcifoannnaioogjmnoooonhcoi`, а у магазинной — другой.
Chrome хранит их списки отдельно и не переносит storage.local автоматически между ID.
Не удаляйте распакованную версию, пока не сохранили нужные домены. Перед тестированием
магазинной версии отключите распакованную, чтобы две копии не меняли одну службу одновременно.

Windows-компонент 0.1.5 принимает оба **конкретных** ID и отклоняет остальные.
Windows-компонент на компьютере издателя уже обновлён и проверен для обоих origin. У новых пользователей старый компонент нужно обновить: иначе магазинный origin не получит доступ.
После одобрения не нужно менять ID, публичный адрес пакета уже закреплён.

## Состояние готовности

Проверены автоматические сценарии, сборка, структура ZIP, геометрия графики и
совместимость двух разрешённых ID. Конкретные результаты находятся в VALIDATION.md.
Одобрение Google не гарантируется; издатель отвечает за точность деклараций и
должен проверить готовую карточку перед отправкой. Само расширение на модерацию
автоматически не отправлялось.
