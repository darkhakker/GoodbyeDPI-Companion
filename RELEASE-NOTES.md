# GoodbyeDPI Companion 0.1.0 — предварительная сборка

Расширение Chrome/Edge и локальный компонент Windows для управления GoodbyeDPI.

## Установка

1. Скачайте **GoodbyeDPI-Companion-Extension.zip** и **GoodbyeDPI-Companion-Windows.zip**.
2. Распакуйте оба архива. В chrome://extensions или edge://extensions включите режим
   разработчика и загрузите распакованную папку **extension**.
3. В Windows-пакете запустите **Install.cmd**, подтвердите UAC.
4. Остановите старую копию GoodbyeDPI, если она работает.
5. В расширении добавьте сайт, включите обход и обновите страницу после обнаружения ресурсов.

Node.js, Python и .NET SDK конечным пользователям не требуются. Нужны Windows 10/11,
.NET Framework 4.8 и права администратора для установки компонента/драйвера.

## Включено

- Служба и Native Messaging host, официальные GoodbyeDPI 0.2.3rc3-2 и WinDivert x86/x64.
- Охват поддоменов и локальное обнаружение сторонних ресурсов добавленного сайта.
- Исключения ресурсов, три фиксированных профиля, отсутствие глобального DNS/QUIC вмешательства.
- SHA256SUMS.json — контрольные суммы двух архивов.

## Состояние

Это preview: автоматические проверки доменов, компиляции и локального протокола пройдены.
Полная установка на чистой Windows и обход блокировок конкретного провайдера не подтверждены.
Собственный Companion.exe пока не подписан. Доступность TikTok не гарантируется.
GitHub ZIP расширения устанавливается через режим разработчика, а не как расширение из магазина.
