# GoodbyeDPI Companion 0.1.1 — автоматическая загрузка компонентов

## Что изменилось

- Поле ввода репозитория и кнопка сохранения адреса удалены.
- При отсутствии компонента Windows расширение автоматически скачивает Setup.exe из нашего релиза.
- Один EXE содержит все зависимости и сам распаковывает файлы перед установкой.
- Появились страница первого запуска, прогресс загрузки и кнопка показа файла.
- Повторное открытие popup не вызывает повторных загрузок; при ошибке доступен явный повтор.
- Старый пользовательский URL больше не влияет на загрузку.

## Установка и обновление

1. Скачайте **GoodbyeDPI-Companion-Extension.zip**, распакуйте и загрузите папку extension
   в chrome://extensions или edge://extensions через режим разработчика.
2. Если расширение уже загружено из локальной папки, замените её файлы и нажмите кнопку обновления
   на странице управления расширениями. Публичный ключ и ID сохранены, список сайтов сохраняется.
3. Если компонент Windows не установлен, Setup.exe начнёт скачиваться автоматически.
   Откройте его из загрузок браузера и подтвердите запрос администратора Windows.
   Вручную искать зависимости, вводить URL или распаковывать Windows ZIP не нужно.

Прямой Setup.exe и Windows.zip доступны в assets как запасные варианты.
Скачивание не даёт расширению права запустить EXE или подтвердить UAC без пользователя.

## Проверки и ограничения

16 тестов JavaScript, сборка C#, проверка Native Messaging и встроенных файлов Setup.exe пройдены локально.
Проверки также запускаются в GitHub Actions. Полная установка с UAC на чистой Windows
и работа обхода у конкретного провайдера пока не подтверждены.
Собственные EXE не подписаны; проверки загрузок браузера и Windows сохраняются.
Нужны Windows 10/11 и .NET Framework 4.8; Node.js/Python/.NET SDK пользователю не требуются.
