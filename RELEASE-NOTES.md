# GoodbyeDPI Companion 0.1.2 — исправлена установка Windows

- Исправлен конфликт переменной установщика с системной переменной PowerShell HOME.
- Добавлен подробный install.log с этапом сбоя и исходной ошибкой.
- Setup.exe показывает подробности ошибки и кнопку открытия журнала.
- В CI добавлена проверка недопустимых присваиваний системным переменным PowerShell.
- Сборка создаёт чистый Windows-пакет без старых журналов установки.

Установка с повышением прав успешно проверена на компьютере пользователя.
Совместимость с конкретным провайдером и чистая Windows требуют отдельной проверки.

Скачайте новое расширение и обновите его в chrome://extensions / edge://extensions.
Если компоненты ещё не установлены, новый Setup.exe загрузится автоматически.
Для исправления уже скачанного установщика можно скачать новый Setup.exe напрямую из assets.
Список сайтов и ID расширения сохранены.
