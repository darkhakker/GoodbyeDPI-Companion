ЕДИНАЯ ЦЕЛЬ
Управление локальным GoodbyeDPI для выбранного пользователем списка сайтов: добавление текущего домена, обнаружение реально запрошенных ресурсов выбранных сайтов и применение списка к локальной службе Windows.

ОБОСНОВАНИЕ storage
Хранит на устройстве выбранные сайты, обнаруженные имена ресурсов, исключения, режим и состояние обхода, согласие на обработку и состояние загрузки установщика. storage.session хранит только последний hostname навигации открытой вкладки для добавления не загрузившегося сайта; запись удаляется при закрытии вкладки. Chrome Sync не используется.

ОБОСНОВАНИЕ nativeMessaging
Необходимо для связи с локальным компонентом org.goodbyedpi.companion в Windows. Расширение передаёт ему только список доменов, фиксированный профиль и состояние включения. Локальная служба управляет GoodbyeDPI/WinDivert; удалённый сервер для этого не используется. Пользователь устанавливает компонент самостоятельно с подтверждением UAC.

ОБОСНОВАНИЕ webRequest
Наблюдает метаданные фактических HTTP/HTTPS-запросов, чтобы обнаруживать точные домены ресурсов выбранного сайта, в том числе поздние запросы видео и вложенных кадров. Также получает hostname неудачной навигации для верхней кнопки добавления текущего сайта. Не запрашивает requestBody/responseBody, cookies и содержимое страниц, не использует blocking/перехват аутентификации.

ОБОСНОВАНИЕ tabs
Читает URL активной вкладки для кнопки добавления текущего сайта и проверяет, что запросы относятся к открытой вкладке выбранного сайта. Проверяет наличие открытой вкладки для однозначной привязки service-worker запросов. При явном добавлении не загрузившейся страницы и включённом движке может повторно загрузить эту вкладку. Полная история Chrome не запрашивается.

ОБОСНОВАНИЕ alarms
Обеспечивает отложенную синхронизацию изменённого списка с локальной службой после обнаружения новых ресурсов, в том числе при остановке service worker Manifest V3. Не используется для рекламы или аналитики.

ОБОСНОВАНИЕ downloads
После явного согласия при первом запуске скачивает один фиксированный установщик необходимого компонента Windows с GitHub Releases, если компонент отсутствует/устарел. Проверяет только известный ID этой загрузки, чтобы показать прогресс, ошибку и расположение файла и не скачивать его повторно. Не читает файлы других загрузок и не запускает EXE автоматически.

ОБОСНОВАНИЕ ДОСТУПА К САЙТАМ http://*/* И https://*/*
Пользователь может добавить любой публичный сайт. Его сторонние домены изображений, скриптов и видео заранее неизвестны; API webRequest требует доступ и к инициатору, и к ресурсу. Расширение обрабатывает запросы ресурсов только в контексте сайтов из пользовательского списка. Для предложения добавить не загрузившийся сайт хранит лишь последний hostname навигации на открытую вкладку в памяти. Данные не используются для рекламы или удалённой аналитики. Обработка начинается только после согласия внутри интерфейса.

УДАЛЁННЫЙ КОД
Нет: расширение не загружает и не исполняет удалённый JavaScript/WASM. Весь код расширения и Public Suffix List находятся в пакете.
ОТДЕЛЬНОЕ ПОЯСНЕНИЕ ДЛЯ ПРОВЕРЯЮЩЕГО: требуется локальное Windows-приложение. Согласившийся пользователь скачивает фиксированный EXE с GitHub, сам запускает его и подтверждает UAC. Это нативный компонент вне среды выполнения расширения, доступный через Native Messaging; его исходный код и бинарные релизы публичны. Нативная зависимость не скрывается под ответом «нет удалённого кода».

КАТЕГОРИИ ОБРАБАТЫВАЕМЫХ ДАННЫХ
Отметить:
• «История веб-поиска / Web history / История посещений» — домены выбранных сайтов и фактически запрошенных ресурсов.
• «Действия пользователя / User activity» — только метаданные сетевых запросов для обнаружения ресурсов, не запись нажатий клавиш или движений мыши.
• «Данные, позволяющие установить личность / Personally identifiable information» — консервативное раскрытие для продукта вместе с нативным компонентом: локальный SID учётной записи Windows и возможные имена в локальных системных путях журналов. Расширение эти идентификаторы не получает; они нужны только для ограничения доступа и диагностики компонента.

Не отмечать финансовые/медицинские сведения, секреты аутентификации, личную переписку, местоположение, содержимое веб-страниц: код расширения их не запрашивает. Чтение URL нужно для выделения hostname, оно не означает чтения DOM/текстов страницы.

НЕ ВЫБИРАТЬ «ДАННЫЕ НЕ ОБРАБАТЫВАЮТСЯ»
Локальная обработка тоже раскрывается согласно требованиям Chrome Web Store. Отсутствие отправки разработчику не отменяет эту обязанность.
