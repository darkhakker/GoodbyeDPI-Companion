GoodbyeDPI Companion 0.1.1 — предварительная версия

1. Откройте chrome://extensions или edge://extensions.
2. Загрузите распакованную папку extension (или нажмите «Обновить» у уже установленного расширения).
3. Если компонента Windows нет, расширение само скачает GoodbyeDPI-Companion-Setup.exe.
4. Откройте этот EXE из загрузок браузера и подтвердите запрос Windows.
5. Всё распакуется и установится автоматически. Вернитесь в расширение, добавьте сайт и включите обход.

Ссылку на репозиторий вводить больше не нужно. Компоненты скачиваются только из
https://github.com/darkhakker/GoodbyeDPI-Companion — релиз v0.1.1-preview.1.
Браузер не может сам запустить скачанный EXE или подтвердить UAC вместо пользователя.

Для GitHub Releases: Setup.exe, Extension.zip, Windows.zip и SHA256SUMS.json из release.
Windows.zip оставлен как запасной способ ручной установки через Install.cmd.
Не запускайте старую службу GoodbyeDPI одновременно с новым движком.
