# Проверки предварительной версии

Дата проверки: 31 октября 2026.

Подтверждено:

- Предыдущая сборка 0.1.5 прошла реальную установку. Для текущего магазинного ID проверяются пересобранный пакет и native-протокол; новая установка на компьютер ещё не выполнялась.
- Исходный загруженный WinDivert64.sys имеет тот же SHA-256 и не перезаписывается; регрессионный тест с заблокированным идентичным файлом проходит.
- Проверено новое оформление: круглый знак с дугами, сливовая/кремовая/янтарная палитра; старые изображения со щитом и стрелкой заменены.

- До первого согласия нет Native Messaging/автоскачивания и записей навигации; отзыв согласия блокирует новые записи.
- Разрешены только точные ID dev abbnpgbcifoannnaioogjmnoooonhcoi и store aekknlficknemkbdbkfcmohdmdblbmhb.
- Скриншоты рендерятся настоящим кодом popup в изолированном headless Chrome с демонстрационными данными; светлая и тёмная палитры проверены.
- Подготовлены три RGB-скриншота 1280×800, RGB-промо 440×280 и 1400×560, иконка 128×128 с прозрачными полями.

- Проверены поздние media-запросы, точный p19-common-sign.tiktokcdn.com, повтор без дубликата, чужой iframe и opaque initiator.
- Общий CDN отдельно связывается с двумя добавленными сайтами только после реального запроса в каждом.
- Service-worker запросы без tabId требуют прямого инициатора выбранного сайта и открытой вкладки; неоднозначные случаи пропускаются.
- Popup обновляет обнаруженные имена через storage.onChanged, сохраняя раскрытую карточку.
- Новый круглый значок с дугами 128 px визуально проверен; размеры 16/32/48/128 сгенерированы из векторной геометрии.

- Проверен popup со старым форматом ответа worker без installer: добавление, отображение и повторное открытие списка.
- Перезапуск фонового worker восстанавливает список из storage.local; повторное добавление не создаёт дубликат.

- Исправленный Install.ps1 завершил реальную установку с UAC с кодом 0 на компьютере пользователя.
- В Windows PowerShell 5.1 проходит проверка синтаксиса и защищённых системных переменных установщика.

- C# скомпилирован встроенным компилятором .NET Framework, с предупреждениями как ошибками.
- 27 тестов Node.js прошли: автоскачивание, защита от дубликатов и повторов после ошибок,
  восстановление после перезапуска worker, миграция старого URL, состояние установки,
  нормализация доменов и IDN, Public Suffix List/PRIVATE,
  защита от доменов-двойников, изоляция выбранного сайта, исключения, удаление,
  ограничение роста, отсутствие предзаданных CDN-семейств, сохранение настроек при недоступном host.
- Self-test нативного компонента прошёл: разбор конфигурации, отклонение неизвестных
  команд, произвольных параметров, публичных доменных зон, слишком больших сообщений,
  проверка профилей и двоичного протокола.
- Реальный Companion.exe корректно отклонил чужой extension origin.
- Setup.exe скомпилирован; проверка --verify-payload проверила все встроенные файлы
  и SHA-256 без распаковки и установки. GUI установки и реальный UAC не запускались.
- Реальная цепочка stdin → Native Messaging host → тестовый локальный named pipe →
  stdout передала запрос и ответ. Выполнено вне песочницы; песочница блокирует эту связь.
  Служба и драйвер при тесте не устанавливались.
- Проверены синтаксис JavaScript/PowerShell, конструкторы ACL установщика и наличие
  всех EXE/DLL/SYS для x86/x64 из официального архива; SHA-256 исходного архива совпал
  с закреплённым значением. Для распространяемых файлов сформированы контрольные суммы.

Не проверено:

- Загрузка расширения в реальный Chrome/Edge и визуальный вид popup.
- Установка на чистой Windows и полное удаление; на компьютере пользователя установка с UAC уже проверена.
- Управление реальным драйвером через новую службу и автоматический запуск после reboot.
- Доступность TikTok у конкретного провайдера; пакеты вне выбранных доменов в capture.

Это предварительная сборка для проверки, а не подтверждённый стабильный релиз.
Старая служба GoodbyeDPI не менялась. По явному разрешению пользователя установлен отдельный GoodbyeDPICompanion.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/native-protocol.ps1
```
